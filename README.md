# מתמטיקה - כל אתרי הלימוד

אתר אחד שמכיל את כל אתרי הלימוד במתמטיקה. כל אתר נמצא בתיקייה משלו, כעותק עצמאי:

| תיקייה | האתר | הועתק מהמאגר |
|---|---|---|
| `algebra-solutions/` | אלגברה לינארית - מדריך פתרונות | algebritqu |
| `algebra-theory/` | אלגברה לינארית - חומר ונוסחאות | algebrit |
| `calculus-1/` | חדו״א 1 - מדריך למבחן | hedva |

- **עריכה:** עורכים ישירות את `<תיקייה>/index.html` כאן. אין קשר למאגרים המקוריים - שינוי כאן לא משנה אותם, ושינוי בהם לא מגיע לכאן.
- **דף הבית:** נבנה אוטומטית ב-Netlify מתוך `sites.json` והאתרים שבתיקיות (`build_hub.py`).
- **מפתח Google לחיפוש החכם:** אחד לכל האתרים (`mathGeminiKey_v1`). מכניסים אותו בדף הבית או בכל אחד מהאתרים. `build_hub.py` מוודא שכל האתרים משתמשים בו.
- **הוספת אתר:** מעתיקים את הקבצים שלו לתיקייה חדשה ומוסיפים רשומה ל-`sites.json` (slug, group, name, kind, description, sources_summary, sources).

## קבצי הקורס בתוך אתר
`tools/files_section.py <תיקייה>` מוסיף לאתר חלק "קבצי הקורס": הקבצים המקוריים כתמונות מדויקות של עמודי ה-PDF (או שקפי המצגת).
בוחרים סוג (שאלות / פתרונות / מצגות) ואז קובץ, ומוצג קובץ אחד בכל פעם. הרשימה ב-`<תיקייה>/files/files.json`.

## סרגל עליון ומפתח
`build_hub.py` מוסיף לכל אתר סרגל עליון קבוע (חזרה לדף הבית + רענון), ומעביר את הגדרת מפתח ה-Google של החיפוש החכם לדף הבית בלבד.
