# מתמטיקה - כל אתרי הלימוד

אתר אחד שמאגד את כל אתרי הלימוד במתמטיקה. כל אתר נלקח מהמאגר שלו בגיטהאב ומתעדכן אוטומטית.

- **רשימת האתרים:** `sites.json`. כדי להוסיף אתר: מוסיפים רשומה (repo, slug, course, name, description).
- **סנכרון:** `sync.py` מוריד את `index.html` העדכני מכל מאגר, מוסיף פס "כל אתרי המתמטיקה" ושם נפרד לזיכרון הגלילה, ובונה את דף הבית.
- **אוטומטי:** `.github/workflows/sync.yml` מריץ את הסנכרון כל רבע שעה (וגם ידנית מלשונית Actions). כשמשהו משתנה הוא שומר, ו-Netlify מפרסם.
- **Netlify:** אין שלב בנייה. מפרסמים את התיקייה הראשית.

המאגרים המקוריים לא משתנים.
