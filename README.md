# מתמטיקה - כל אתרי הלימוד

אתר אחד שמכיל את כל אתרי הלימוד במתמטיקה. כל אתר נמצא בתיקייה משלו, כעותק עצמאי:

| תיקייה | האתר | הועתק מהמאגר |
|---|---|---|
| `algebra-solutions/` | אלגברה לינארית - מדריך פתרונות | algebritqu |
| `algebra-theory/` | אלגברה לינארית - חומר ונוסחאות | algebrit |
| `calculus-1/` | חדו״א 1 - מדריך למבחן | hedva |

- **עריכה:** עורכים ישירות את `<תיקייה>/index.html` כאן. אין קשר למאגרים המקוריים - שינוי כאן לא משנה אותם, ושינוי בהם לא מגיע לכאן.
- **דף הבית:** נבנה אוטומטית ב-Netlify מתוך `sites.json` והאתרים שבתיקיות (`build_hub.py`).
- **הוספת אתר:** מעתיקים את הקבצים שלו לתיקייה חדשה ומוסיפים רשומה ל-`sites.json` (slug, course, name, description).
