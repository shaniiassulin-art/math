🔑 מפתח לחיפוש החכם - אחד לכל האתרים

החיפוש החכם (העלאת תמונה של תרגיל) עובד דרך Gemini של Google, בחינם. מדביקים כאן את המפתח פעם אחת, והוא עובד בכל האתרים שבדף הזה, בטלפון או במחשב הזה.

  1. נכנסים ל-aistudio.google.com/apikey עם חשבון Google ומאשרים את התנאים.
  2. לוחצים Create API key ומעתיקים את המפתח.
  3. מדביקים אותו כאן ולוחצים "שמירה".

המפתח שמור בדפדפן הזה, והחיפוש החכם מוכן בכל האתרים.
