# אלגברה לינארית - חומר ונוסחאות

אתר לימוד עם כל החומר התיאורטי של הקורס, לפי שתי המצגות: **מספרים מרוכבים** ו**מטריצות**.
בכל נושא: הגדרות, משפטים ונוסחאות, הסבר במילים, דוגמאות מחושבות והוכחות (בתיבות מתקפלות), ודף נוסחאות מסכם בסוף כל חלק.

- `index.html` - האתר (קובץ יחיד)
- `source-map.md` - מיפוי בין סעיפי האתר לפרקי המצגות

## חיפוש חכם (AI)
כפתור "✨ חיפוש חכם" מקבל תמונה או טקסט של תרגיל, ומפנה לסעיפים הרלוונטיים באתר.
- בגרסת Claude (artifact) החיפוש עובד דרך חשבון ה-Claude של מי שצופה בדף, בלי הגדרות.
- באתר הזה (GitHub) החיפוש עובד דרך Gemini של Google בשימוש החינמי: צריך מפתח חינמי מ-aistudio.google.com/apikey, שנשמר רק בדפדפן ונשלח רק ל-Google.
